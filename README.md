# OKNA — сайт оконного мастера

Сайт-визитка с админкой: продажа, установка и ремонт металлопластиковых окон.
Языки: итальянский (главный), английский, украинский, русский, молдавский.

- `/` итальянский, `/en/`, `/uk/`, `/ru/`, `/md/` остальные языки
- `/admin/` админка

## Как это устроено

- **Сайт статический.** Это готовые HTML-страницы без сервера и базы данных, поэтому взламывать нечего. Хостинг Cloudflare Pages бесплатный.
- **Скорость.** Сайт не тянет фреймворков: CSS встроен в страницу, скрипт весит около 4 КБ, шрифты хранятся на самом сайте. Фото отдаются в формате WebP в нескольких размерах. Карта и видео загружаются только по клику.
- **Админка** работает на [Sveltia CMS](https://sveltiacms.app). Каждое изменение сохраняется коммитом в этот репозиторий, после чего Cloudflare за 1–2 минуты пересобирает и публикует сайт. Вся история правок хранится, и любую можно откатить.
- **Защита админки.** Войти может только тот, у кого есть доступ на запись к этому репозиторию на GitHub. Сама страница `/admin/` без входа ничего не умеет. Включите двухфакторную аутентификацию на GitHub.

## Что можно менять в админке

**Тексты сайта** (на каждом из 5 языков) — все тексты, кнопки, услуги, схема технологии, таблица стеклопакетов, цены, варианты покупки, этапы, монтаж, ремонт и прайс, галерея, отзывы, вопросы, форма, SEO.

**Настройки и дизайн** (общие для всех языков):
- контакты: телефон, WhatsApp, Telegram, e-mail, адрес, карта, логотип;
- соцсети: Instagram, Facebook, Telegram, WhatsApp, Viber, TikTok, YouTube, VK, LinkedIn;
- дизайн: светлая или тёмная тема, 4 цвета, 4 варианта шрифтов, форма углов;
- первый экран: 3 вида (фото в раме окна / на весь экран / пополам) с одним фото, слайд-шоу или видео;
- блоки страницы: порядок меняется перетаскиванием, любой блок можно скрыть;
- видео-блок: ссылка YouTube или свой mp4;
- форма заявки: на e-mail через Web3Forms или в WhatsApp.

Фото и видео загружаются прямо в админке. Картинку можно вставить и по ссылке.

## Первый вход в админку

1. Откройте `https://<ваш-адрес>.pages.dev/admin/`.
2. Нажмите **Sign In Using Access Token**.
3. Создайте токен: GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
   - Repository access: *Only select repositories* → `okna`
   - Permissions → Repository: **Contents: Read and write**
4. Вставьте токен в админку. Он хранится только в вашем браузере.

Чтобы входить кнопкой «Sign in with GitHub» без токена, можно поднять бесплатный [sveltia-cms-auth](https://github.com/sveltia/sveltia-cms-auth) на Cloudflare Workers и прописать `base_url` в `admin/config.yml`.

## Публикация на Cloudflare Pages (один раз)

1. dash.cloudflare.com → **Workers & Pages** → Create → вкладка **Pages** → **Connect to Git** → репозиторий `spevyakin-web/okna`.
2. Настройки сборки:
   - Framework preset: **None**
   - Build command: `npm run build`
   - Build output directory: `dist`
3. **Save and Deploy**.

После этого каждый push в `main` и каждое сохранение в админке публикуют сайт за 1–2 минуты. Сайт будет по адресу `https://okna-xxx.pages.dev`.

Заголовки безопасности и кэширования задаются в `public/_headers`. Версия Node указана в `.node-version`.

Свой домен: в проекте Cloudflare Pages → Custom domains, затем в админке «Настройки → SEO → Адрес сайта».

## Заявки на e-mail

Получите бесплатный ключ на [web3forms.com](https://web3forms.com) и вставьте его в «Настройки → Форма заявки». Без ключа форма открывает WhatsApp с готовым текстом заявки.

## Локальная разработка

```bash
npm install
npm run dev        # сборка и локальный сервер
```

Структура:

```
content/home.json      тексты на 5 языках (it, en, uk, ru, ro)
content/settings.json  контакты, соцсети, дизайн, порядок блоков
public/uploads/        загруженные фото и видео
src/                   стили, иконки, скрипт страницы
admin/                 админка (config.yml — описание полей)
build.mjs              сборщик → dist/
```

## Перед запуском

- Цены, отзывы, цифры и контакты — это **примеры**. Замените их на настоящие.
- Демо-фото взяты с Unsplash по [Unsplash License](https://unsplash.com/license) и подгружаются с их CDN. Лучше заменить их реальными фото работ мастера.
